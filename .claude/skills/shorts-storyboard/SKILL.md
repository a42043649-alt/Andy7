# 숏폼 스토리보드

대본을 영상으로 옮기는 중간 단계다. 목적은 두 가지: (1) 촬영/소재 준비 목록을 사람이 보기 쉽게 정리, (2) 렌더 스크립트가 바로 읽는 `storyboard.json` 생성.

## 절차

1. `script.md`를 읽는다. 없으면 `shorts-script-hook`을 먼저 제안한다.
2. 대본 한 줄 ≈ 한 장면. 장면 길이는 **1.5~4초**: 2초 미만은 정신없고 5초 넘으면 지루하다. 전체 합이 목표 길이와 맞는지 계산한다.
3. 장면마다 정한다:
   - `caption`: 화면 자막. 15자 안팎, 최대 2줄. 내레이션을 그대로 옮기지 말고 핵심어 위주로 줄인다 (소리 끄고 보는 사람이 많다).
   - `media`: 사용할 파일 경로. 아직 없으면 비워두고 `note`에 "무엇을 찍을지/어떤 이미지가 필요한지" 적는다. 비워두면 렌더 시 단색 배경 카드로 대체된다.
   - `note`: 촬영/제작 메모, AI 이미지 프롬프트 등 (렌더에는 영향 없음).
4. 첫 장면(훅)은 가장 시각적으로 강한 소재 + 큰 자막. 마지막 장면은 CTA.
5. 세로 안전영역을 지킨다: 화면 하단 약 25%와 상단 약 10%는 플랫폼 UI(캡션·버튼)에 가려진다. 핵심 피사체와 자막은 중앙 영역에 둔다. (렌더 스크립트는 자막을 이 영역 밖에 두도록 기본 설정돼 있다.)
6. 사용자에게 소재 체크리스트(필요한 촬영/이미지/음원 목록)를 요약해 보여주고, 있는 것만으로 먼저 렌더해도 되는지 묻는다.

## storyboard.json 형식

필드 상세와 예시는 `../shorts-video-render/references/storyboard-spec.md` 참고. 최소 형태:

```json
{
  "output": "shorts/my-video/short.mp4",
  "voiceover": null,
  "music": null,
  "scenes": [
    {"duration": 3, "caption": "이 한 줄로\n월 12만 원 절약", "media": null, "note": "손에 든 영수증 클로즈업"},
    {"duration": 3, "caption": "방법은 간단해요", "media": "shorts/my-video/a.jpg"}
  ]
}
```

내레이션 파일이 있으면 장면 길이 합을 그 길이에 맞춘다 (`ffprobe -v error -show_entries format=duration -of csv=p=0 vo.mp3`로 확인).

## 같이 내놓는 것

`storyboard.json` 외에 사람이 읽는 표(장면, 시간, 자막, 필요 소재)를 대화에 보여준다. 파일은 `shorts/<영상이름>/`에 저장한다.
