# 업로드 패키지

같은 영상이라도 플랫폼마다 글이 놓이는 자리가 다르다. 대본(`script.md`)의 훅과 키워드를 재사용해 일관되게 쓴다.

## 플랫폼별 작성 기준

| | 인스타 릴스 | 유튜브 쇼츠 | 틱톡 |
|---|---|---|---|
| 제목 | 없음 (캡션 첫 줄이 제목 역할) | 필수, 40자 안팎, 핵심어 앞쪽 | 없음 |
| 캡션/설명 | 첫 1~2줄이 승부 (더보기 전에 보임), 이후 가치 보충 | 1~2문장 + 관련 링크 | 짧게 1~2줄 |
| 해시태그 | 3~5개, 주제+니치 혼합 | `#Shorts` 포함 3개 안팎 (제목/설명) | 3~5개 |
| 커버 | 프로필 그리드에서 보임 → 커버 문구 필수 | 자동 프레임 or 직접 선택 | 선택 |

수치(권장 길이·해시태그 수·최대 길이)는 플랫폼 정책이 바뀌므로, 사용자가 정확한 한도를 물으면 단정하지 말고 업로드 화면에서 확인하라고 안내한다.

## 절차

1. `script.md`(없으면 사용자에게 주제/영상 내용을 묻는다)에서 훅, 핵심 키워드, CTA를 뽑는다.
2. 요청된 플랫폼만 작성한다 (모르면 세 곳 모두).
3. **제목 후보 3개**, 캡션 1세트, 해시태그 세트(대형 1 + 중형 2 + 니치 2 정도로 섞기), 커버 문구(최대 2줄 8자씩), 고정댓글 1개(질문형으로 댓글 유도).
4. 아래 체크리스트로 마무리한다.

## 업로드 전 체크리스트

- [ ] 1080x1920, 세로(9:16), 길이가 플랫폼 한도 이내
- [ ] 첫 프레임이 훅 (검은 화면·로고로 시작하지 않음)
- [ ] 자막이 하단 UI에 가려지지 않음 (미리보기 화면에서 확인)
- [ ] 음원 저작권: 상업 계정이면 플랫폼 제공 음원/저작권 프리 음원만
- [ ] 훅이 약속한 내용을 영상 안에서 회수함
- [ ] 캡션에 CTA는 하나만

## 출력 형식

플랫폼별 섹션으로 복붙 가능한 상태로 보여준다. 파일로 저장하면 `shorts/<영상이름>/publish.md`.
