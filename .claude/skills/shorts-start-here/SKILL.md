# 숏폼(릴스·쇼츠) 제작 지도

숏폼은 "주제 → 대본(훅) → 스토리보드 → 렌더 → 업로드 패키지" 5단계로 나눠 만들면 어디서 막혀도 그 단계만 다시 하면 된다. 단계마다 스킬이 있고, 앞 단계의 결과물 파일이 다음 단계의 입력이 된다.

| 단계 | 스킬 | 입력 | 결과물 |
|---|---|---|---|
| 1. 대본·훅 | `shorts-script-hook` | 주제/아이디어, 채널 정보 | `script.md` (훅 3안 + 본문 + CTA) |
| 2. 스토리보드 | `shorts-storyboard` | `script.md` | `storyboard.json` (장면별 길이·자막·소스) |
| 3. 렌더 | `shorts-video-render` | `storyboard.json` + 이미지/영상/음성 | `short.mp4` (1080x1920) |
| 4. 업로드 패키지 | `shorts-publish-pack` | `script.md` | 플랫폼별 제목·캡션·해시태그·커버 문구 |

## 시작할 때 확인할 것 (모르면 한 번에 물어본다)

1. **채널/주제**: 무엇에 대한 영상인가? (예: 요리, 재테크, 영어, 제품 소개)
2. **플랫폼**: 인스타 릴스 / 유튜브 쇼츠 / 틱톡 (여러 개면 길이는 가장 엄격한 쪽에 맞춘다)
3. **소재**: 직접 찍은 영상, 이미지, 음성(내레이션)이 있는가? 없으면 텍스트+이미지 카드형으로 간다.
4. **언어/톤**: 기본은 한국어, 구어체.

## 단계 판단

- 아이디어만 있다 → 1단계부터
- 대본이 있다 → 2단계부터
- 영상 파일/이미지가 이미 있다 → 2단계에서 장면 구성만 하고 3단계로
- 영상은 이미 완성 → 4단계만

## 준비물 (3단계에 필요)

- `ffmpeg` (영상 합성), `python3` — 렌더 스크립트가 쓴다
- 한글 폰트 (Noto Sans CJK KR, Pretendard, 나눔고딕 중 하나) — 없으면 자막이 깨진다
- 내레이션이 필요하면 직접 녹음하거나 TTS 파일을 준비한다 (스크립트는 오디오 파일을 받기만 한다)

중간 결과물은 `shorts/<영상이름>/` 폴더에 모아두면 다음 단계에서 찾기 쉽다.
